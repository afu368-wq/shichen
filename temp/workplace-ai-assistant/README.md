# 职场时位 AI 小助手 (MVP)

专为职场女性设计的每日时位建议助手，基于传统历法与现代职场心理学的结合。

## 项目概述

**核心定位**：职场避坑导航仪，而非算命工具  
**目标用户**：25-40 岁职场女性，关注工作效率与情绪管理  
**技术栈**：微信原生小程序 + CloudBase 云函数 + 百度文心千帆 API

## 核心算法

### 1. 四柱计算（本地模拟）
```javascript
// utils/lunar.js
calculateFourPillars(year, month, day, hour) → {
  year: '丙午', month: '癸巳', day: '壬戌', hour: '丙午',
  dayMaster: '壬水', dayBranch: '戌'
}
```

### 2. 十神与关系
- **十神映射**：天干 → 十神（伤官/食神/正财等）
- **地支关系**：日支 vs 今日地支 → 逢冲/逢合/平和

### 3. 每日更新
- 每日 0:00 自动过期缓存
- 重新计算今日标签
- 调用云函数获取新建议

## 云函数架构

### dailyAdvice 云函数
```javascript
输入: { tenGod, relation, todayGanZhi }
处理:
  1. 组装职场教练 Prompt
  2. 调用百度文心千帆 API
  3. msgSecCheck 内容安全检测
  4. 返回 JSON 格式建议
输出: { advice: [{title, content, icon}] }
```

### 环境变量配置
```bash
# CloudBase 环境变量
BAIDU_ACCESS_TOKEN=xxx  # 百度文心千帆 API Key
```

## 数据流

```
用户输入生日/时辰/出生地
    ↓
本地计算四柱（首次需云函数校正）
    ↓
每日：读本地四柱 → 算十神+关系
    ↓
发送标签到云函数 → 调用 AI → 安全检测
    ↓
返回 3 条建议 → 本地缓存 → UI 展示
```

## 隐私与安全

### 数据存储策略
- **本地**：加密后的四柱特征码（非明文生日）
- **云端**：仅存储匿名化特征，不存个人身份信息
- **AI 输入**：仅传递十神标签，不传递生日等敏感信息

### 合规性
1. 所有 AI 输出经过 `msgSecCheck` 检测
2. UI 明确标注“仅供职场策略参考”
3. 禁止玄学话术，使用“职场博弈、情绪边界”等专业词汇

## 快速启动

### 1. 导入微信开发者工具
1. 打开微信开发者工具
2. 导入项目目录 `workplace-ai-assistant`
3. 填入你的小程序 AppID（或使用测试号）

### 2. 本地测试
1. 点击“编译”
2. 首次进入会跳转到信息录入页面
3. 填写测试信息（如：1990-01-01，午时，北京市）
4. 进入首页查看今日卡片

### 3. 云函数部署
1. 在 CloudBase 控制台创建环境
2. 上传 `cloudfunctions/dailyAdvice` 目录
3. 配置环境变量 `BAIDU_ACCESS_TOKEN`
4. 在小程序中配置云函数调用
